プライバシー

ひとことで言うと、拡張機能も、このサイトも、何も集めません。応援の支払いはStripeが扱います。最終更新：2026年10月30日。

拡張機能

  • アカウントなし、分析なし、追跡なし。閲覧履歴も設定も統計も、どこにも送りません。
  • すべてブラウザの中に。設定、カウンター（今日と累計のブロック数）、ザップした広告、テーマ、言語は、あなたのパソコンのChrome拡張機能ストレージに保存されます。アンインストールすると消えます。
  • リモートコードなし。フィルターリストは拡張機能に同梱。ブロックはChrome内蔵のルールエンジンで行います。
  • アップデーター（GitHub版のみ）。GitHubからインストールして任意のアップデーターを設定した場合、新しいバージョンがあるかGitHubに確認してダウンロードします（git pull と同じ）。GitHubにはその通信が見えます。ストア版はストア経由で更新されます。
  • AIコントロール（近日公開）。あなたのパソコン上で動き、つないだAIアプリとだけやりとりします。私たちのサーバーは通りません。そもそもサーバーがありません。

このサイト

  • Cookieなし、分析なし、トラッカーなし、広告なし。
  • ブラウザに残すのは2つだけ。言語やテーマを選ぶと、次のページも同じ表示になるようブラウザのローカルストレージに記憶します。端末の外には出ません。
  • ホスティング。このサイトはCloudflareで動いています。一般的なホスティングと同じく、ページの配信と攻撃対策のためにIPアドレスが処理されます。あなたを特定するためには使いません。

応援について

  • 支払いはStripe経由。カード情報は私たちには見えず、保存もしません。領収書とお礼のために、お名前・メール・国・金額がStripeから共有されます。詳しくはStripeのプライバシーポリシーをご覧ください。
  • GitHub Sponsorsで応援する場合は、GitHubのプライバシーステートメントに沿って同じように扱われます。
  • いつでも解約OK。月額の方は、Stripeの領収書メールのリンク、またはトップページの「毎月の応援を管理する」から変更・解約できます。
  • 返金。気が変わったら、請求から14日以内にご連絡ください。返金します。
  • 応援してくれた方の情報を、売ったり貸したり他者と共有したりはしません。
