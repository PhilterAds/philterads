ChromeとEdgeでポップアップをブロックする方法

ChromeとEdgeには、はじめからポップアップブロッカーが入っています。オンになっているかの確認方法、通知スパムの止め方、そして標準機能では防げないポップアップについて説明します。最終更新：2026年10月31日。

1. 標準のブロッカーをオンにする（パソコン）

  1. Chrome：chrome://settings/content/popups を開き（または 設定 → プライバシーとセキュリティ → サイトの設定 → ポップアップとリダイレクト）、ポップアップとリダイレクトを許可しない設定を選びます。
  2. Edge：edge://settings/content/popups を開き（または 設定 → Cookie とサイトのアクセス許可 → ポップアップとリダイレクト）、ブロック をオンにします。
  3. 銀行や予約サイトなど、ポップアップが必要な信頼できるサイトは、ブロッカーを切るのではなく許可の一覧に追加しましょう。

2. Android版Chrome

  1. ⋮ メニュー → 設定 → サイトの設定 → ポップアップとリダイレクト を開きます。
  2. スイッチがオフ（ブロックする状態）になっていることを確認します。

PhilterAdsのようなパソコン向けの拡張機能はAndroid版Chromeでは動かないため、こちらでは標準の設定が頼りです。

3. 通知スパムを止める

「ポップアップ」の多くは、うっかり許可してしまったサイトの通知です。サイトを閉じていても表示されることがあります。

  1. chrome://settings/content/notifications（Edgeは edge://settings/content/notifications）を開きます。
  2. 通知を許可しているサイトの一覧から、心当たりのないサイトを削除します。
  3. 今後たずねられたくない場合は、サイトに通知の送信を許可しない設定を選びます。

4. それでもポップアップが出る理由

  • クリックで開くタブ。 標準のブロッカーは、ページが勝手に開くウィンドウを止めます。多くの広告スクリプトは、ページのどこかをクリックした瞬間にタブを開くため、ブラウザは「ユーザーの操作」とみなして通してしまいます。
  • ページ内のオーバーレイ。 メルマガ登録の枠やCookieバナー、「通知を許可しますか？」のような表示はページの中に描かれたもので、ブラウザのポップアップではありません。
  • 広告からのリダイレクト。 タブごと別のサイトへ飛ばす広告はリダイレクトで、この設定では一部しか防げません。

5. 拡張機能でできること

コンテンツブロッカーは、どのサイトが広告ネットワークかを知っているため、こうしたケースにも対応できます。たとえばPhilterAdsは、EasyListのポップアップルールに当てはまる広告や詐欺のタブをすぐに閉じます。自分で開いたタブや、同じサイトの新しいタブはそのままです。FanboyのCookie / Annoyanceリストで、Cookieバナーやオーバーレイの多くも隠します。無料・オープンソースで、お金をもらって広告を通すことはありません。

6. 「ウイルスが見つかりました」という偽の警告が閉じないとき

  • 表示された電話番号に電話したり、すすめられたものをダウンロードしたりしないでください。本物のブラウザやウイルス対策ソフトが電話を求めることはありません。
  • Shift + Esc でブラウザのタスクマネージャーを開き、そのタブを選んで プロセスを終了 します。
  • そのあと手順3の通知一覧を確認してください。詐欺の警告は、通知の許可を通じて戻ってくることがよくあります。
