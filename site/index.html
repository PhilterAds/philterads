Features

What Sip does all day

More of Sip's tricks

YouTube, with the ads gone before they start.

The player's ad data is removed before the player reads it. If anything slips through, Sip mutes it, skips to the end and clicks Skip for you. No countdown, no waiting.

Trackers caught. Malware sites locked out.

Six filter lists, including EasyPrivacy and the URLhaus malware list, refreshed every week. Sneaky trackers get bubbled, known malware domains never load at all, and pop-up ad tabs are closed the moment they open.

Cookie banners? Sip prefers the real ones.

Turn on the Cookie banners list and the consent walls crumble. It's off by default, because hiding the wrong thing is worse than seeing a banner, and it's one tap to change.

Site acting up? Let Sip nap.

One toggle pauses PhilterAds on just that site, and the master switch sends Sip to sleep everywhere. Both are reversible from the same spot.

Install

Install from GitHub in about a minute

The Chrome Web Store and Edge Add-ons listings are in review. Until they go live, install the same build straight from our GitHub releases.

  1. 1

    Download

    Get philterads.zip, the latest release.

    Download for Chrome & Edge
  2. 2

    Unzip it

    Extract it into a folder you'll keep, such as Documents\PhilterAds. The browser runs PhilterAds from that folder, so don't delete it.

  3. 3

    Open extensions

    Paste this into the address bar: chrome://extensionsIn Edge, use edge://extensions. Brave and Vivaldi work the same way.

  4. 4

    Turn on Developer mode

    It's a switch at the top right in Chrome, and in the left sidebar in Edge.

  5. 5

    Load unpacked

    Click Load unpacked and pick the folder that has manifest.json in it. Then pin Sip from the puzzle-piece menu.

Updating. Download the new zip, unzip it over the same folder, then press the reload arrow on the PhilterAds card. Your settings and zapped ads stay. Once the store listings are live, updates happen on their own.

Why there's no .exe installer. Chrome and Edge only accept extensions from their stores or through Developer mode. Installers that push an extension in behind the browser's back are how adware works, so we won't ship one.

FAQ

Questions people ask Sip

Is it really free?

Yes, and it stays free. No premium tier changes what gets blocked. If you want to help, sponsoring is optional and buys you a thank-you, not a feature.

Is it safe? What do you collect?

Nothing. PhilterAds has no account, no analytics and no remote code; the only network requests are the page's own. This website is the same: no cookies, no analytics. The only things it stores in your browser are your language and theme choices. Full privacy page.

Will YouTube punish me for blocking ads?

Banning accounts for using an ad blocker is not something YouTube is known to do. What YouTube does do, sometimes, is show a notice that ad blockers are against its terms, or slow playback for people it detects. PhilterAds is built to avoid triggering those. If you ever see one, pause PhilterAds on youtube.com, reload, and tell us on GitHub. Using an ad blocker is your choice; what YouTube allows is up to YouTube.

Does it block pop-ups?

Yes. PhilterAds is a pop-up blocker as well as an ad blocker. When a page tries to open an ad or scam pop-up in a new tab, Sip closes it straight away, using the pop-up rules from EasyList. Tabs you open yourself, and new tabs on the same site (like a login or payment window), are never touched.

Does it break sites?

It's built not to. The project's first rule is "never break a site": a protected allow-list covers sign-in, payment and captcha services, and every build is tested against it. If something still looks wrong, pause PhilterAds on that site from the popup and reload. If that fixes it, report the site and we'll fix the rule.

Why open source?

Because "we never let ads through for money" only means something if you can check. The code is GPLv3 and public on GitHub, the filter lists are credited, and pull requests that add tracking get closed.

Which browsers?

Chrome and Edge first, built on Manifest V3. Brave, Vivaldi and Arc install it from the Chrome Web Store too. Firefox (desktop and Android) comes next, then Opera, with Safari later.

What's under the hood?

Chrome's declarativeNetRequest, with rules built from EasyList, EasyPrivacy and the URLhaus malware list, plus Fanboy's cookie and annoyance lists you can turn on. Lists are refreshed every week.
